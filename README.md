# Daniel Duque Urrego — Personal Portfolio

A responsive, single-page portfolio designed for GitHub Pages.

## Before publishing

Replace these placeholders in `index.html`:

- `your-username` with your GitHub username
- `your-email@example.com` with the email address you want to publish
- `https://www.linkedin.com/in/your-username` with your LinkedIn URL
- Project repository slugs with the repositories you want to feature
- The CV / résumé link with a public PDF or repository file, if desired

## Publish with GitHub Pages

1. Create a new public repository named `<your-username>.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
5. Save. Your site will be available at `https://<your-username>.github.io/` after GitHub finishes publishing it.

No build step or framework is required.
